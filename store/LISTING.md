## English

**Name:** TabToTable AI
**Summary (132 char max):** Turn all your open tabs into one AI-built comparison table — pricing, features, whatever you're researching, in one click.

**Description:**
Doing competitor research, comparing SaaS tools, or shopping around? You already have 10-40 tabs open. TabToTable AI reads them and builds one clean comparison table — columns, rows, and a link back to every source — in seconds.

- Scans every open http(s) tab in the current window (configurable limit)
- Uses Claude (Sonnet 5 or Haiku 4.5, your choice) to pick relevant columns automatically
- Export to CSV or Markdown, sortable and searchable
- Local scan history (last 5)
- Your Anthropic API key stays local — sent only, directly, to Anthropic's API
- Free: 150 tabs/month
- Available in English and Hebrew (RTL)

You need your own Anthropic API key ([console.anthropic.com](https://console.anthropic.com/settings/keys)).

**Category:** Productivity
