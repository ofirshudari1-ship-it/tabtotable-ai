The Problem

המחקר לא נגמר בפתיחת לשוניות — הוא נתקע בהעתקה ביניהן

עושים מחקר מתחרים, משווים ספקים, בודקים כלי SaaS — הדפוס תמיד זהה: פותחים עשרות לשוניות, ואז מתחילים לעבור אחת-אחת ולהעתיק ידנית שם, מחיר, פיצ'ר, לגיליון אקסל.

Updates

איך מקבלים גרסה חדשה

⚠ no auto-update

התוסף לא מתעדכן אוטומטית. Chrome מריץ עדכון אוטומטי רק לתוספים שמותקנים מ-Chrome Web Store (דרך update_url שגוגל שולט בו). TabToTable AI מותקן במצב מפתח (Load unpacked) ולכן אין לו שום מנגנון עדכון — Chrome פשוט לא בודק אם יש גרסה חדשה.

כדי לעבור לגרסה חדשה:

  1. נכנסים ל-github.com/ofirshudari1-ship-it/tabtotable-ai/releases ומורידים את קובץ ה-zip של הגרסה החדשה.
  2. פותחים chrome://extensions, מסירים (Remove) את הגרסה הישנה של TabToTable AI.
  3. מחלצים את ה-zip החדש ולוחצים Load unpacked על התיקייה המחולצת.

אם/כשהתוסף יפורסם ב-Chrome Web Store, זה ישתנה — עדכונים יתקינו את עצמם אוטומטית כמו כל תוסף רגיל. עד אז, זו הדרך היחידה.

Install

התקנה במצב מפתח

התוסף עדיין לא בחנות Chrome Web Store — ההתקנה היא Load unpacked, תהליך חד-פעמי של כ-2 דקות.

1

מורידים את TabToTable-AI-v0.7.0.zip מ-GitHub Releases ומחלצים לתיקייה.

2

פותחים chrome://extensions ומפעילים "מצב מפתח".

3

לוחצים Load unpacked ובוחרים את התיקייה המחולצת (זו שמכילה את manifest.json).

4

פותחים את הגדרות התוסף ומזינים מפתח Anthropic API אישי.

5

פותחים כמה לשוניות, לוחצים על האייקון — והטבלה הראשונה מוכנה.

הוראות מלאות ופתרון תקלות קובץ INSTALL.md בתיקיית הפרויקט כולל טבלת פתרון תקלות מלאה, כולל טעויות נפוצות במפתח ה-API ובמכסה החודשית. רוצים להבין את הארכיטקטורה? מסמך SPEC.md מפרט את הבעיה, הפתרון, המגבלות הידועות ומפת הדרכים המלאה.
